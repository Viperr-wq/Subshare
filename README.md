# SubShare — совместная оплата подписок

**SubShare** — сервис для совместной оплаты подписок. Пользователь создаёт группу
(например, «Netflix, 6000 ₸, 4 человека»), добавляет друзей, а SubShare сам считает
долю каждого и показывает, кто уже заплатил, а кто ещё должен.

В репозитории две части:

- **`app/` — серверная часть (API)** на Python + FastAPI с базой данных;
- **`mobile/` — мобильное приложение** на React Native + Expo. Из одного кода получаются
  приложения для Android и iOS и веб-версия, которая открывается по ссылке.

Приложение отправляет запросы на сервер и показывает пользователю ответы.

### Что умеет API

- **входить через Telegram-бота**: человек нажимает «Войти через Telegram» и делится в боте
  номером — его подтверждает сам Telegram, пароль не нужен. Сервер выдаёт ключ входа (токен),
  без него остальные эндпоинты не работают; ключи хранятся в базе только в виде хеша.
  Вход по паролю остался только для демо-пользователей на своём компьютере (`seed.py`);
- **проверять права**: группу видят только её участники, менять — только владелец,
  перевод отмечает сам плательщик, а получение денег подтверждает владелец;
- создавать группу подписки: сервис, цена, до какого числа платить, лимит участников;
- **редактировать группу** (например, при подорожании подписки): доли пересчитываются сами,
  а уже выставленные счета остаются прежними — их сумма зафиксирована при начислении;
- удалять группу;
- добавлять участников, выходить из группы и убирать участника (с проверкой лимита тарифа);
- **приглашать друга по имени и номеру**: если его ещё нет в SubShare, для него создаётся
  аккаунт, и друг получает его, когда сам войдёт через Telegram с этим номером;
- показывать все группы пользователя;
- **автоматически делить цену** на всех участников в целых тенге
  (6000 ₸ / 4 = 1500 ₸; 5000 ₸ / 3 = 1667 + 1667 + 1666 ₸);
- при выходе участника **пересчитывать доли** (6000 ₸ / 3 = 2000 ₸);
- выставлять счета участникам за месяц (владелец сам платит сервису, ему счёт не выставляется);
- показывать по группе за месяц: сколько собрать, сколько собрано, кто просрочил;
- показывать пользователю все его неоплаченные счета во всех группах и **кому переводить**
  (имя и номер владельца группы);
- отмечать перевод («Я перевёл») и подтверждать получение денег — или отвечать «Не пришли»;
- **сам выставлять счета** в начале месяца и **напоминать в Telegram** за день до срока
  и после него (`POST /tasks/daily`, раз в день по расписанию);
- писать ошибки на языке приложения: русском, казахском или английском;
- **удалять аккаунт** со всеми данными (этого требуют магазины приложений и закон).

## Почему выбраны именно эти технологии

| Технология | Что это | Почему подходит SubShare |
|---|---|---|
| **Python** | Язык программирования | Один из самых простых для новичков, много материалов на русском |
| **FastAPI** | Фреймворк для создания API | Мало кода; сам проверяет входящие данные; **автоматически создаёт страницу документации**, где любой эндпоинт можно проверить кнопкой в браузере |
| **SQLite** | База данных на компьютере | Хранится в одном файле, ничего устанавливать не нужно |
| **PostgreSQL** (Neon) | База данных на хостинге | Бесплатный хостинг стирает файлы при перезапуске, а облачная база хранит данные постоянно |
| **SQLAlchemy** | Библиотека для работы с БД | Таблицы описываются как Python-классы. Один и тот же код работает и с SQLite, и с PostgreSQL |
| **pytest** | Тесты | Автоматически проверяет, что расчёты и эндпоинты работают правильно |
| **React Native + Expo** | Мобильное приложение | Один код на JavaScript — приложения для Android и iOS и веб-версия по ссылке |
| **Render** | Хостинг | Бесплатно запускает сервер и сайт прямо из GitHub; настройки лежат в файле `render.yaml` |

### Про способ оплаты

Платёжная система ещё выбирается, поэтому в MVP деньги через SubShare не проходят:
участники переводят свою долю владельцу привычным способом (например, Kaspi),
а в SubShare платёж отмечается как оплаченный.

Подключение платёжной системы в структуре базы уже учтено: в таблице `payments`
есть поле `method` (сейчас всегда `manual` — ручной перевод) и поле `external_id`
для номера транзакции у провайдера. Когда будет выбран провайдер (Halyk ePay,
Freedom Pay или другой), таблицы переделывать не придётся — добавится новый
способ оплаты и код, который отмечает платёж оплаченным после ответа провайдера.

## Как запустить сервер на компьютере (пошагово)

### 1. Установите Python

Скачайте Python 3.10 или новее с [python.org](https://www.python.org/downloads/).
**На Windows** при установке обязательно поставьте галочку **«Add Python to PATH»**.

Проверка — откройте терминал (на Windows: «Командная строка» или PowerShell) и введите:

```bash
python --version
```

Должно появиться что-то вроде `Python 3.12.4`. (На macOS команда может называться `python3`.)

### 2. Откройте папку проекта в терминале

```bash
cd путь/к/папке/subshare-backend
```

Удобнее всего открыть папку в [VS Code](https://code.visualstudio.com/) и использовать
встроенный терминал (меню **Terminal → New Terminal**) — он сразу откроется в нужной папке.

### 3. Создайте виртуальное окружение и установите библиотеки

Виртуальное окружение — это отдельная «коробка» с библиотеками только для этого проекта.

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

После активации в начале строки терминала появится `(venv)`.

> Если PowerShell пишет, что выполнение скриптов запрещено, выполните один раз
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повторите активацию.

### 4. (Необязательно) Заполните базу демо-данными

```bash
python seed.py
```

Создадутся 6 пользователей и 4 группы (Netflix, Spotify, YouTube Premium, Яндекс Плюс)
со счетами за текущий месяц. Демо-вход — номер +7 701 000 00 01, пароль `demo2026`
(такой же у всех демо-пользователей).

Если база уже заполнена старыми демо-данными, `seed.py` её не трогает. Чтобы начать
заново, остановите сервер, удалите файл `subshare.db` и снова выполните `python seed.py`.

### 5. Запустите сервер

```bash
fastapi dev app/main.py
```

### 6. Откройте в браузере

- **http://127.0.0.1:8000/docs** — документация API, где можно нажимать и проверять эндпоинты;
- http://127.0.0.1:8000/ — проверка, что сервер работает (остальные адреса просят ключ входа).

Остановить сервер: `Ctrl + C` в терминале.

## Как запустить приложение на компьютере

Нужен [Node.js](https://nodejs.org/) версии 22 (LTS). Во втором терминале выполните:

```bash
cd mobile
npm install
npx expo start
```

- Нажмите `w` — приложение откроется в браузере.
- На телефоне: установите приложение **Expo Go** и отсканируйте QR-код из терминала.
  Если Expo Go пишет, что версия SDK не поддерживается, откройте веб-версию по ссылке
  или установите APK ([DEPLOY.md](DEPLOY.md), шаг 8).

По умолчанию приложение работает с сервером на Render. Чтобы подключить его к серверу
на своём компьютере, скопируйте файл `mobile/.env.example` в `mobile/.env` и перезапустите `npx expo start`.

## Как открыть сайт на компьютере

Сайту не нужна сборка. В отдельном терминале, из корня проекта:

```bash
python -m http.server 5500 -d site
```

Откройте http://localhost:5500. На компьютере сайт работает с сервером `fastapi dev`
(он должен быть запущен). Telegram-бота на компьютере нет, поэтому окно входа покажет ошибку
и кнопку **«Демо-вход»** (нужен `python seed.py`). Регистрация по почте на компьютере работает:
письмо не отправляется, а код из него печатается в терминале сервера.
Сайт (порт 5500) и приложение (порт 8081) здесь на разных адресах, поэтому вход с сайта
в приложение не переносится. На хостинге адрес общий — переносится.

Страница статистики — http://localhost:5500/admin.html. Её видят только номера из `ADMIN_PHONES`,
поэтому сервер для проверки запустите так (PowerShell):

```powershell
$env:ADMIN_PHONES="+77010000001"; fastapi dev app/main.py
```

## Как проверить API в браузере (сценарий для демонстрации)

На странице **/docs** у каждого эндпоинта есть кнопка **Try it out** → **Execute**.
Почти все эндпоинты работают только с ключом входа, поэтому сначала нужно войти.

1. Запустите `python seed.py` и выполните **POST /login**: номер `+77010000001`,
   пароль `demo2026`. В ответе есть `token` — ключ входа. У остальных демо-пользователей
   (`+77010000002` … `06`) пароль тот же. Люди в приложении входят через Telegram.
2. Нажмите **Authorize** вверху страницы и вставьте `token`: дальше вы действуете
   от имени этого пользователя. Сменить пользователя — **Logout** в том же окне
   и `token` другого.
3. **POST /groups** — создайте группу: `total_price: 6000`, `max_members: 4`.
   Владельцем станет тот, чей ключ вставлен.
4. **POST /groups/{group_id}/invite** — добавьте остальных троих по имени и номеру.
5. **GET /groups/{group_id}** — видно, что у каждого доля 1500 ₸.
6. **POST /groups/{group_id}/payments/{period}** — укажите `period` = `2026-10`:
   трём участникам выставлено по 1500 ₸.
7. **POST /payments/{payment_id}/sent** — от имени участника отметьте перевод,
   затем **POST /payments/{payment_id}/pay** — от имени владельца подтвердите, что деньги пришли.
8. **GET /groups/{group_id}/payments/{period}** — собрано 1500 ₸, осталось 3000 ₸.
9. **DELETE /groups/{group_id}/members/{user_id}** — уберите участника, доли станут по 2000 ₸.
10. **PATCH /groups/{group_id}** — поднимите цену: `total_price` = `8000`. Доли в карточке
    группы пересчитаются, а счёт за уже выставленный месяц останется прежним.

Проверка прав: вставьте в **Authorize** ключ второго пользователя — **PATCH** этой группы
ответит 403 «Это может только владелец группы». Без ключа любой эндпоинт ответит 401.

## Что дальше

- **Вход без Telegram** — для тех, у кого его нет (например, код по SMS; нужен договор
  с SMS-сервисом).
- **Приглашения по ссылке** — чтобы добавить друга в группу одной ссылкой.
- **Миграции базы (Alembic)** — чтобы менять таблицы, не удаляя данные.
- **Хранение данных в Казахстане** — по закону РК о персональных данных основная база
  должна находиться в Казахстане. Перед запуском с реальными пользователями базу
